BAAPU NA PAISA — COMPLETE OFFLINE APP

Files in this package are the complete website/PWA.

UPLOAD TO A NEW GITHUB REPOSITORY
1. Create a new empty repository named baapu-na-paisa (or any name you prefer).
2. Upload ALL files and folders from this extracted package to the repository root.
3. Keep the folders exactly as supplied: icons/ and assets/.
4. Commit the files.
5. In GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.
6. Wait for Pages to publish, then open the Pages URL.

The PIN screen uses assets/pin-money-image.jpeg (your second image).
The dashboard banner uses assets/dashboard-money-image.jpeg (your third image).
The White Money and Black Money cards do not show the two explanatory subtitles.

DATA & SECURITY
This app works offline after first load and stores data in this browser/device only.
The 4-digit PIN is a simple local app lock, not strong encryption. Export JSON backups regularly.
