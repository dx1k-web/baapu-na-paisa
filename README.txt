Baapu na paisa — Spider-Man-inspired red/blue PWA theme

This package uses your supplied reference artwork as the app icon and logo, with a red/blue comic-book web-inspired interface theme.

Deploy every file in this folder to a static HTTPS host. On iPhone, open the HTTPS site in Safari > Share > Add to Home Screen.

The app stores entries locally in this browser/device. No cloud sync is included. Export JSON regularly. Clearing Safari website data may remove entries. The 4-digit PIN is an app-entry lock, not encryption.
