🕸️ Baapu na paisa

💰 Your Money. Your Rules.

A personal, offline-first money management app designed to track two separate money accounts in one place.

Built with a Spider-Man-inspired red and blue theme, simple interface, and mobile-first experience.

⸻

🦸 Features

💵 White Money

* Track money received from parents.
* Separate balance management.
* Track income and expenses.

🐺 Black Money

* Track personally saved money.
* Independent balance tracking.
* Separate transaction history.

💸 Money Management

* Add Money.
* Spend Money.
* Split Payments.
* Transfer between accounts.
* Track pending payments.
* Prevent overspending.

📊 Dashboard & Reports

* Total available money.
* Total spending.
* Pending payments.
* Monthly expense reports.
* Category-wise spending.
* Savings goals and budgets.

📜 Transaction History

* View all transactions.
* Search transactions.
* Filter by category and account.
* Edit and delete transactions.

🔐 Privacy & Security

* 4-digit PIN lock.
* Local data storage.
* No mandatory account registration.
* No cloud synchronization.

💾 Backup & Restore

* Export JSON backups.
* Export CSV transaction records.
* Restore previous backups.

⸻

🎨 Design

* Spider-Man-inspired red and blue theme.
* Comic-style visual elements.

* Smooth and modern UI.

📱 Platform Support

* iPhone
* iOS Safari
* Android browsers
* Desktop browsers

Installable through the browser’s Add to Home Screen feature where supported.

⸻

🌐 Hosting

Hosted using GitHub Pages.

The application is designed to work offline after its initial successful load and caching.

⸻

🔒 Data & Privacy

* Personal transaction data is stored locally on the device.
* No cloud synchronization is included.
* Regular backups are recommended.
* Clearing browser website data may remove stored information.
* The PIN is an app lock, not full device-grade encryption.

Never upload personal financial records or backup files to this public repository.

⸻

🚀 Installation

1. Open the application URL in Safari.
2. Tap the Share button.
3. Select Add to Home Screen.
4. Tap Add.
5. Open Baapu na paisa from your Home Screen.
